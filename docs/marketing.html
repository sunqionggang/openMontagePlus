FAQ

常见问题

BYOK（Bring Your Own Key）意味着你用自己注册的 API Key（如 OpenAI、可灵、百炼），平台不代付、不锁量、不涨价。你的 Key 加密存储，仅在任务运行期间注入进程，绝不写入日志，也绝不向其他用户暴露。你也可以随时在设置页吊销。
可以。你只需要在创作台用一句话描述想做的视频（例如"用动画解释 HTTP 和 HTTPS 的区别，90 秒"），AI 会自动完成选题、脚本、分镜、素材生成、配音和剪辑。也可以直接套用模板市场里的 13 条流水线。
生成费用由你自己的 Key 承担，可精确到每步对账。一个 60 秒动画的典型成本约 ¥0.5–2（创意 LLM + 视频生成 + TTS），具体取决于你选的模型。平台订阅费（专业版 ¥29/月）只覆盖基础服务。
默认完全隔离——你的项目、Key、作品、账单只有你自己可见。如果你愿意，可以一键"发布到公共广场"展示给所有用户，也可以随时下架。
支持 9:16（抖音/快手/视频号）、16:9（B站/YouTube）、1:1（信息流）三种比例，分辨率 720p / 1080p / 4K，H.264 + AAC。成片可下载 MP4，另可导出 SRT 字幕文件。
用户数据以 SQLite 本地存储（可自托管），密码使用 PBKDF2 加盐哈希；API Key 加密保存且只在任务运行时注入；作品默认私有。完整开源自托管（AGPLv3），可部署在你自己的服务器上。
